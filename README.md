# Mi primera web

Página web estática simple, creada como ejercicio para la electiva de Cloud Computing (Ingeniería de Sistemas). Muestra una tarjeta de presentación con imagen, título y descripción, desplegada en la nube.

## Estructura del proyecto

```
mi-primera-web/
├── index.html      # Página principal
├── styles.css       # Estilos de la página
└── images/
    └── nube.jpg      # Imagen usada en la página
```

## Tecnologías

- HTML5
- CSS3

## Cómo verla localmente

Basta con abrir el archivo `index.html` en cualquier navegador, o servirlo con un servidor estático simple, por ejemplo:

```bash
npx serve .
```

## Despliegue

El sitio está desplegado en [Vercel](https://mi-primera-web-six.vercel.app/), aprovechando que es un sitio 100% estático (HTML/CSS) y no requiere backend.
